# Instructor notes — 02.2 Vodka and gin

- **Objective:** learner can name the EU gin categories, recognise core botanicals by smell and choose a sensible substitute.
- **Likely confusion:** gin vs distilled gin vs London gin; "London" read as a place.
- **Misconception:** "vodka has no taste so any vodka works anywhere". It is neutral, but texture and base material show in spirit-forward drinks, and flavoured vodka is a different product.
- **Expected hands-on result:** blind score 3–5/6 on the first try; juniper and citrus identified, coriander often confused with citrus. The juniper-heavy blend should read as "gin-like".
- **Extension:** repeat the blend with a local herb (za'atar, sage, lemon verbena) to design a "Mediterranean gin" profile and describe it in two guest-friendly sentences.
