# Instructor notes — 01.7 Hygiene, setup and reset: the timed station drill

- **Objective:** learner applies hand washing, clean-rinse-sanitise-dry and labelling, and completes the Module 1 timed drill within targets with no safety failure.
- **Likely confusion:** cleaning vs sanitising; many think a sanitiser spray "cleans".
- **Misconception:** speed first. The drill is designed so that a safety failure ends the run; reinforce that this mirrors the final assessment (outline §6).
- **Expected hands-on result:** run 1 setup 8–12 minutes; run 3 at or near 6:00; resets under 1:30 by run 2. Calibration usually passes if 01.3 was done.
- **Targets:** setup ≤ 6:00, reset ≤ 1:30, close ≤ 10:00 are professional judgment for a home station (consistent with `templates/practice-log.md` example). Real bars vary.
- **Extension:** after passing, run the drill with a friend calling three random orders during the service round; add a fourth reset.
- **Currency:** FDA Food Code 2026 (released 2026-09-17) is cited as a model code; Israeli requirements are in Module 9. Re-verify on later updates.
