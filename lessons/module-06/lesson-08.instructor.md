# Instructor notes — 06.8 Build a twelve-cocktail menu

- **Objective:** module practical piece: a 12-drink menu (≥ 6 families, ≥ 3 methods, ≤ 6 shaken, ≥ 3 lighter, ≥ 4 bases, ≤ 4 glass types, ≥ 2 alcohol-free with cards, allergen note per row, one sourced local serve), prep list, guest-facing order, four-drink test run, rubric self-score (20 points, pass 14). Costing columns stay empty for 10.5.
- **Likely confusion:** whether alcohol-free drinks count toward the 12. They do not: rows 13+.
- **Misconception:** "a menu is a list of my favourite drinks" and "mocktails are optional". The rubric scores balance, speed, allergens and real alcohol-free options.
- **Expected hands-on result:** first drafts over-index on sours and shaken drinks; after the check, 3–4 sours; four-drink ticket 3–5 minutes in home-practice form (professional judgment). Example solution scores 19/20.
- **Extension:** ask the learner to write a winter version of the same menu that changes only four drinks and keeps the prep list the same size.
- **Link forward:** lesson 10.5 costs and prices this exact CSV with the costing calculator; tell learners to keep the file.
- **Note:** all targets in the balance table are professional judgment, not industry rules.
