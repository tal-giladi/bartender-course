# Instructor notes — 05.6 Mojito and Moscow Mule

- **Objective:** recall IBA Mojito (45 white rum / 20 lime / 6 mint sprigs / 2 tsp sugar / soda) and Moscow Mule (45 vodka / 120 ginger beer / 10 lime); muddle mint gently; build long drinks keeping fizz; safe Mule vessel.
- **Likely confusion:** IBA Mojito names no glass and no soda amount. Course: highball, about 60–90 ml soda to fill (professional judgment); house spec decides.
- **Misconception:** "muddle mint hard to get more flavour". Gentle pressing releases the surface oils; grinding mainly adds shreds and grassy notes (professional judgment, widely taught).
- **Expected hands-on result:** Mojito time falls to about 60–80 s by the fourth; Mule 20–30 s; careful Mule loses less weight (CO2) in 5 minutes than a roughly built one.
- **Extension:** time a six-Mojito round using the across-the-glasses method.
- **Sources caveat:** copper guidance is via Wikipedia's summary of the FDA Model Food Code (pH below 6.0) and the 2017 Iowa ABD advisory; the exact Food Code edition was not checked directly.
- **Safety:** muddling in thick glass only; knife caution.
