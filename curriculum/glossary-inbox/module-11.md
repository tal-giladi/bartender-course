# Glossary inbox — Module 11

- **Final assessment** — the course's closing set of exams (written, recipe recall, technique, service, guest scenarios, costing) and a performance report; self-scored, not a qualification (lessons/module-11/lesson-01.md)
- **Weighted total** — the sum of each component score multiplied by its weight; the final assessment needs at least 80.0 (lessons/module-11/lesson-01.md)
- **Component minimum** — the lowest score a component may have for the assessment to be passed, whatever the total (lessons/module-11/lesson-01.md)
- **Safety-critical failure** — a mistake that fails the part it occurs in whatever the score, such as serving a possible minor without ID or scooping ice with a glass (lessons/module-11/lesson-01.md)
- **Rubric** — a scoring guide that says what each score looks like for each criterion (lessons/module-11/lesson-01.md)
- **Exam conditions** — closed book (except costing), one sitting, no restarts; the first complete run of an exam preset counts (lessons/module-11/lesson-01.md)
- **Remediation** — targeted, logged practice on what went wrong before a retake (lessons/module-11/lesson-01.md)
- **Seed** — a number that fixes a simulation's random draw; a retake uses a new seed (lessons/module-11/lesson-02.md)
- **Exam set** — the fixed series of movements filmed twice in the technique exam (lessons/module-11/lesson-03.md)
- **Service score** — accuracy minus a time penalty (above 300 s average ticket time) and a waste penalty (above 5% waste) (lessons/module-11/lesson-04.md)
- **Negative variance** — less stock used than the POS says should have been used; flagged like over-use (lessons/module-11/lesson-06.md)
- **Performance report** — the learner's final summary of scores, result, strengths, areas to improve and remediation plan (lessons/module-11/lesson-07.md)

## Hebrew

- Trial shift — משמרת ניסיון (mishmeret nisayon) — a try-out shift before a bar hires you
- Final assessment — הערכה מסכמת (ha'arakha mesakemet) — the closing evaluation of a course
- Exam — מבחן (mivchan) — a test
- Score — ציון (tziyun) — a mark or grade
- Feedback — משוב (mashov) — comments on performance
