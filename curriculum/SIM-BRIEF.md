## Rules
- `simulations/<name>/index.html` + its own `.js`/`.css`; shared code only in `simulations/common/` (check what exists; add, don't clobber): `common/sim.css`, `common/sim.js` (label, query parsing, seeded RNG, safe storage, CSV export via `data:` link with `download`), `common/bar-math.js` (pure calculation functions), `common/recipes.js` (generated by `scripts/build_recipes.py` from `curriculum/recipes.yaml` — never edit by hand; if a recipe is missing, report it).
- Plain HTML + CSS + vanilla JS. No framework, bundler, npm, CDN, external fonts or any network request.
- Use classic `<script src>` files (IIFE / global namespace), not `type="module"` (ES modules do not load from `file://`). `bar-math.js` must also work under Node for tests (`if (typeof module !== "undefined") module.exports = …`).
- Works in a sandboxed iframe (`allow-scripts` only): no cookies, no parent access, localStorage optional in try/catch, no alert/prompt/confirm/popups/top navigation.
- Responsive from 360 px; keyboard-usable (real buttons/inputs, labels, focus styles); light and dark (`prefers-color-scheme`).
- Visible label: "Educational model — not a real bar".
- Presets from `?preset=<x>`; support every preset the lessons link, plus a sensible default. Show what the preset trains and a task with a target. `exam` presets show a final score breakdown matching outline §6 and a "copy results" text block for the performance report.
- Deterministic where possible (seeded RNG `&seed=<n>`; "new shift / re-run" changes the seed).
- Every visible control works. No decorative buttons.
