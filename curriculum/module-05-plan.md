# Module 05 plan — Classic Cocktails I

Planning file, not imported. Written 2026-10-17.

Module practical piece: 05.8 recipe recall drill (all 12 drinks, blank grid scored to the 11.2 standard: ml exact ±5 ml, method, glass, garnish) + a home session making all 12 as home-practice or alcohol-free versions, logged in `labs/module-05/twelve-drink-log.csv` and `templates/practice-log.md`.
Simulations linked: recipe-drill `m05` (05.1, every drink lesson, 05.8).
Recipes: IBA spec is the card's default (checked on iba-world.com 2026-10-17); variations from Difford's Guide recipe pages and the Aperol brand site, each named on the card. Data for all 12 in `curriculum/recipe-inbox/module-05.yaml`.
Unit convention as in Module 3 and `simulations/common/bar-math.js`: 1 oz = 30 ml (bar convention), barspoon 5 ml, dash 0.8 ml. IBA amounts given as dashes, cubes, teaspoons or "a shot" stay as unit strings.
