# Module 06 plan — Classic Cocktails II and Menu Knowledge

Planning file, not imported. Written 2026-10-17.

Module practical piece: 06.8 build a twelve-cocktail menu across at least six families, each drink with spec source, method, glass, a home-practice/NA version and costing placeholders (finished with real prices in 10.5). Files: `labs/module-06/menu-builder.csv`, `labs/module-06/menu-brief.md`, `labs/module-06/twelve-cocktail-menu-solution.md`.
Simulations linked: recipe-drill `m06` (every drink lesson, 06.8) and `families` (06.1, 06.6, 06.8).
Recipes: IBA spec is the card's default (checked on iba-world.com 2026-10-17). The Tom Collins has no IBA page: the IBA John Collins page says to use Old Tom gin for a Tom Collins, so the card uses that spec with Old Tom gin and names the source. Gimlet and Hugo Spritz are not IBA drinks: Difford's Guide is the card source, labelled as such. Arak serves in 06.7 come from Saveur (arak and grapefruit) and Adam Montefiore (arak with water). Variations from Difford's Guide recipe pages, each named on the card. Data in `curriculum/recipe-inbox/module-06.yaml`; ids checked against `module-05.yaml` (no clash).
Unit convention as in Modules 3 and 5: 1 oz = 30 ml, bar spoon 5 ml, dash 0.8 ml; dashes, pieces, leaves and "to top" stay as amount strings.
