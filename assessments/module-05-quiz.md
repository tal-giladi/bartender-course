# Module 5 quiz — Classic Cocktails I

This quiz checks how you use Module 5 behind a bar: recalling the twelve IBA classics in ml, choosing the right method, glass and garnish, telling the IBA spec from a named variation, adapting when an ingredient is missing, and handling the safety points that come with these drinks (egg white, copper mugs, caffeine with alcohol). The questions are short scenarios; pick what a careful working bartender would do. Pass mark: 70%. You can retake it.
