# Dilution experiment — run plan (lesson 03.5)

Record results in `templates/dilution-worksheet.md` (add rows to 8) or in the table below. Non-alcoholic.

Mix for every run (room temperature): 60 ml water + 22.5 ml lemon juice + 22.5 ml 1:1 syrup. Weigh it; it is about 110 g because syrup is heavier than water.
Ice for every run: 150 g, same source, same waiting time out of the freezer.

Dilution % = (weight after − weight before) ÷ weight before × 100.
