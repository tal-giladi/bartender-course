# Module 3 labs — Measurement, Dilution and Flavor Science

Worksheets for the Module 3 hands-on work. Print them or copy them into a notebook or spreadsheet. Everything here is non-alcoholic: water, cold tea, lemons or limes, sugar syrup, soda water and ice, measured with a jigger and a kitchen scale (1 g steps).

| File | Lesson | What it is |
|---|---|---|
| `scaling-worksheet.md` | 03.1 | 10 conversion, parts, scaling and batch-water problems |
| `scaling-worksheet-solution.md` | 03.1 | Worked answers — check only after answering |
| `scaling-sheet.csv` | 03.1 | Batch calculation as a spreadsheet (open in Excel, Google Sheets or LibreOffice and fill the blanks) |
| `free-pour-drill.md` | 03.2 | Free-pour count and syrup-by-weight drill with tolerances |
| `balance-experiment.md` | 03.3 | Syrup ladder, salt on bitter, temperature and aroma tests |
| `syrup-juice-log.md` | 03.4 | Syrup density and yield, juice yield, sweetness swap and freshness tests |
| `dilution-experiment.md` | 03.5 | Eight timed shake, stir and build runs, predicted then weighed |
| `fizz-test.md` | 03.6 | Careful versus careless highball: fizz, taste and weight loss |
| `unbalanced-drinks.md` | 03.7 | Module practical: six fault cards for a partner, scoring sheet |
| `unbalanced-drinks-solution.md` | 03.7 | Answer key for the fault cards |

Templates used alongside: `templates/dilution-worksheet.md`, `templates/tasting-notes.md` and `templates/practice-log.md`.

Data: no external datasets. Unit values match the course calculators (1 oz = 29.57 ml, bar convention 30 ml, barspoon 5 ml, dash 0.8 ml). Syrup densities from The Engineering ToolBox sucrose table (50% ≈ 1.23 g/ml at 20 °C; 2:1 interpolated ≈ 1.33). Expected ranges in the solution files are professional judgment from home trials, checked 2026-10-17; your own measurements are the result that counts.
