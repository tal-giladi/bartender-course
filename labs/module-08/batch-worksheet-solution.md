# Batch worksheet — solution (lesson 08.3)

Numbers follow the recipe scaler (`batch`: water = undiluted batch × dilution; serving = total ÷ N).

## 1. Manhattan for 24, fridge, 40%

| | Answer |
|---|---|
| Rye | 50 × 24 = 1,200 ml |
| Sweet vermouth | 20 × 24 = 480 ml |
| Angostura | 24 dashes × 0.8 = 19.2 ml |
| Undiluted batch | 1,699.2 ml |
| Water | 1,699.2 × 0.40 = 679.7 → 680 ml |
| Total | 2,378.9 → about 2,379 ml |
| One serving | 2,378.9 ÷ 24 = 99.1 ml (pour 100 ml) |
| ABV | alcohol 480 + 76.8 + 8.6 = 565.4 ml → 33.3% before; 33.3 ÷ 1.4 = 23.8% after |
| Storage | Fridge. At about 24% it freezes near −11 °C, so it slushes in a −18 °C freezer. |

## 2. Negroni for 30

Pre-mix, no water: each serving is poured over ice and stirred in the glass, so the ice adds the water. 900 + 900 + 900 = 2,700 ml; one serving 90 ml. Container about 3 L (10% headspace). Fridge or cool, dark shelf; vermouth inside it fades at room temperature, so the fridge is better (lesson 08.2).

## 3. Dry Martini for 12, 20% water

Undiluted 60 × 12 = 720 ml gin + 10 × 12 = 120 ml vermouth = 840 ml. Water 168 ml. Total 1,008 ml. Serving 84 ml.

a) 40% gin: alcohol 288 + 21.6 = 309.6 ml → 36.9% before → 36.9 ÷ 1.2 = 30.7% after. Freezes at about −15 to −16 °C: in a −18 °C freezer it may slush. Use a freezer set to about −12 °C, less water, or the fridge.
b) 47% gin: alcohol 338.4 + 21.6 = 360 ml → 42.9% before → 35.7% after. Freezes below about −19 °C: safe in a −18 °C freezer.

## 4. Event Daiquiri for 40

Day before: rum 2,400 ml + syrup 600 ml = 3,000 ml pre-mix, no water, labelled. On the day, within a few hours of service: 800 ml lime (about 27 limes at 30 ml each), added to the pre-mix or kept separate. One serving: 3,800 ÷ 40 = 95 ml, shaken on ice, double strained.
Label: "Daiquiri pre-mix × 40 + lime. NO water: shake 95 ml with ice, double strain. Lime added [day] [time], discard at close. [initials]."

## 5. Spot the mistake

Undiluted batch 90 × 10 = 900 ml; the 360 ml is 40% water. Because every serving is shaken on ice, the ice adds its water again: the drinks are thin, weak and too large (126 ml per serving before shaking instead of 90 ml). The batch should have been a pre-mix with no water: 450 ml bourbon + 250 ml lemon + 200 ml syrup, labelled "NO water, shake 90 ml", with the lemon added on the day.
