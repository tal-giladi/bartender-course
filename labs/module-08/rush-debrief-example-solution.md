# Example rush debrief — compare after writing your own (lesson 08.8)

One learner's runs, written up with `templates/service-debrief.md`. Numbers are an example, not targets.

## Run 1 (rush)

| Metric | Result | Target |
|---|---|---|
| Preset and seed | rush, seed 41 | |
| Orders completed | 20 tickets, 51 drinks | |
| Accuracy (%) | 84 (43 of 51 correct) | ≥ 90 |
| Average ticket time (s) | 352 | ≤ 300 |
| Waste | 6% (five dead drinks, one remake) | ≤ 5% |
| Stock-outs handled | lime juice low at ticket 14, fetched myself (45 s) | |

What happened:

- Slowest ticket: T5, four Mojitos (412 s). It waited behind T1–T4, and I made the four Mojitos one at a time: four muddles, the rum bottle picked up four times.
- Mistakes: five dead drinks in wave 1 (built drinks iced first, then shaken drinks made after them); a Paloma without the pinch of salt; a French 75 served in a coupe instead of a flute.
- Lost time: fetching lime juice myself; picking bottles up again and again on three-drink tickets.

Causes in one line each: sequence (ice too early, no passes), recall (two Module 6 details), stock (no early barback request).

**One change for run 2:** every ticket of three or more drinks in passes, with ice going in last: shaken first, then built drinks, tops last.

## Run 2 (rush)

- Station: ask the barback for lime juice when the bottle shows "low", not "empty".
