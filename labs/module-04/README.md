# Module 4 labs — Mixing Methods and Technical Skills

Worksheets, logs and checklists for the Module 4 hands-on work. Print them or open them in a spreadsheet. All practice uses water, ice, tea, sugar syrup, citrus, mint, soda and aquafaba or pasteurised egg white; no alcohol is needed.

| File | Lesson | What it is |
|---|---|---|
| `method-sort-cards.md` | 04.1 | 20 IBA drinks, ingredients only: choose the method and give a reason |
| `method-sort-cards-solution.md` | 04.1 | IBA methods, deciding ingredients and accepted alternatives — check only after answering |
| `technique-drill-log.csv` | 04.2–04.8 | One row per rep: target, measured, error %, time, pass/fail. The 80 rows for the 04.8 drill are pre-filled; add rows for other lessons |
| `garnish-tray-checklist.md` | 04.7 | Hygiene, tray, twist and salt-rim checklist with targets |
| `technique-drill-sheet.md` | 04.8 | Module practical: setup, targets, pass rules and rubric conversion for each movement, plus the demonstration comparison table |

Templates used alongside: `templates/technique-rubric.md`, `templates/practice-log.md`, `templates/station-checklist.md`.

Data: no external datasets. Methods on the sort cards come from the IBA official cocktail pages (https://iba-world.com/cocktails/), checked 2026-10-17. Targets and tolerances come from the lessons and the course templates; time targets marked in the lessons as professional judgment are practice standards, not industry rules.
