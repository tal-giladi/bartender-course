# Module 6 labs — Classic Cocktails II and Menu Knowledge

Cards, worksheets and spreadsheets for the Module 6 hands-on work and the module's practical piece (lesson 06.8, a twelve-cocktail menu). All drink practice is alcohol-free: water, teas, juices, syrups, soda and aquafaba stand in for spirits, liqueurs and egg white.

| File | Lesson | What it is |
|---|---|---|
| `family-sort-cards.md` | 06.1 | 24 IBA drinks by ingredients only: write the family and method |
| `family-sort-cards-solution.md` | 06.1 | Families, accepted alternatives, IBA methods and deciding clues — check only after answering |
| `substitution-worksheet.md` | 06.6 | Eight substitution, adaptation and naming scenarios |
| `substitution-worksheet-solution.md` | 06.6 | Model answers with reasons |
| `menu-claims-sort.md` | 06.7 | Twelve statements about Israeli bar menus to label verified, judgment or unknown |
| `menu-claims-sort-solution.md` | 06.7 | Labels and sources |
| `israeli-menu-survey.csv` | 06.7 | Survey sheet for three real Israeli bar menus (one example row to delete; not real data) |
| `menu-builder.csv` | 06.8 | Module practical: 12 cocktail rows + alcohol-free rows; costing columns left empty for Module 10 |
| `menu-brief.md` | 06.8 | Bar description, balance count, prep list, guest-facing order, test run and the 20-point rubric |
| `twelve-cocktail-menu-solution.md` | 06.8 | One example menu with balance count and prep list — compare after scoring your own |

Templates used alongside: `templates/recipe-card.md`, `templates/practice-log.md`, `templates/tasting-notes.md`.

Data: specs and methods come from the IBA official cocktail pages (https://iba-world.com/cocktails/all-cocktails/) and, where stated, Difford's Guide recipe pages, all checked 2026-10-17. The arak serves come from Adam Montefiore (2019) and Saveur, named in lesson 06.7. Balance targets, prep amounts and time ranges are professional judgment for practice, not industry rules. Units: 1 oz = 30 ml (bar convention), bar spoon 5 ml, dash about 0.8 ml.
