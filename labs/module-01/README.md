# Module 1 labs — Bar Foundations and Equipment

Worksheets and printable cards for the Module 1 hands-on work. Print them or copy them into a notebook or spreadsheet. All practice uses water, ice, citrus and kitchen equipment; no alcohol.

| File | Lesson | What it is |
|---|---|---|
| `home-station-list.md` | 01.2 | Shopping and setup sheet with rough ₪ prices (professional judgment), station map box, blind reach test |
| `measurement-drill.md` | 01.1, 01.3, 01.7 | Pour-by-weight drill sheet with tolerances |
| `measurement-drill.csv` | 01.1, 01.3, 01.7 | Same drill as a spreadsheet (open in Excel, Google Sheets or LibreOffice) |
| `tool-id-cards.md` | 01.3, 01.5 | 20 description cards: name the tool or glass and one use |
| `tool-id-cards-solution.md` | 01.3, 01.5 | Answers to the cards — check only after answering |
| `glass-capacity-worksheet.md` | 01.5 | Measure your glasses and map them to bar glass types |
| `station-drill-scoresheet.md` | 01.7 | Module practical: timed setup, reset and close drill, with safety items |

Templates used alongside: `templates/practice-log.md` and `templates/station-checklist.md`.

Data: no external datasets. Capacities and tolerances come from the lessons (sources listed there); prices are rough professional judgment as of 2026-10-17.
