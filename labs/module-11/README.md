# Module 11 labs — Final Assessment

Exam sheets, cases, data and worked solutions for the final assessment (lessons 11.1 to 11.7). Everything is self-scored; nothing here is independently verified unless a reviewer signs the technique form. Open a `*-solution.md` file only after you have finished and scored the matching part.

| File | Lesson | What it is |
|---|---|---|
| `exam-score-sheet.md` | 11.1–11.7 | Exam plan, every attempt with date and seed, written-score blend, weighted total |
| `grading-cases.md` | 11.1 | Three candidates to grade: written score, weighted total, minimums, safety |
| `grading-cases-solution.md` | 11.1 | Worked answers |
| `recall-exam-grid.md` | 11.2 | Paper version of the recall exam: numbered list of 30 drinks, 20-row grid, marking rules, error log |
| `technique-exam-sheet.md` | 11.3 | The exam set, filming rules, evidence log, evidence-to-rubric table, safety-critical check |
| `reviewer-form.md` | 11.3 | Optional form for a working bartender who reviews the films |
| `service-exam-sheet.md` | 11.4 | Plan, results, penalties and service score, debrief prompts |
| `guest-exam-cases.md` | 11.5 | Three new written guest cases |
| `guest-exam-cases-solution.md` | 11.5 | Model answers and scoring notes |
| `costing-exam-brief.md` | 11.6 | Assignment data, formulas, answer sheet and marking tolerances |
| `costing-exam-inventory.csv` | 11.6 | Par levels, counts, deliveries and logged waste for five bottles |
| `costing-exam-solution.md` | 11.6 | Full worked solution and an example report |

Grading model (lesson 11.1): written 20% (0.50 × Module 11 quiz + 0.25 × lesson-quiz average + 0.25 × guest scenarios exam), recall 25%, technique 25%, service 20%, costing 10%; minimums 70, 80, 75, 70, 70; pass = weighted total ≥ 80.0, every minimum met, no safety-critical failure.

Data and sources: prices from `labs/module-10/price-list.csv` (Shufersal online regular retail prices incl. VAT and course assumptions, checked 2026-10-18) plus ginger beer 330 ml at 5.90 ILS incl. VAT (course assumption); VAT 18% (Israel Tax Authority, checked 2026-10-18). Candidates, sales, counts, waste logs, garnish costs and example results are invented for practice. Specs are the course cards (IBA unless stated, checked 2026-10-17). Legal references in the guest cases are from Module 9 (checked 2026-10-18).
