## 3. Mark (after the timer stops)

Mark against the course specs in the [recipe library](../../references/recipe-library.md) (IBA unless the lesson's card says otherwise). One point per cell, only if fully right:

- **Ingredients and ml:** every ingredient named and every ml within ±5 ml; dashes, cubes, sprigs, bar spoons and "to top" as the spec says. A variation's spec (for example Difford's instead of IBA) scores only if the course card names it as an accepted alternative.
- **Method:** the right technique and its key step (dissolve sugar, dry shake for egg, top with soda last).
- **Glass and ice:** the right glass and the ice in it, or "no ice".
- **Garnish:** the spec garnish ("none" where the spec has none).

Total: ____ / 80 = ____ % (minimum 80%). Copy it to the exam score sheet.
