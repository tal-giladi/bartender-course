# Incident log (printable)

Use for refusals of service, ID refusals, allergy incidents, injuries, broken glass in ice, aggressive guests and any time emergency services were called. Write it as soon as it is safe to do so, in facts, not opinions. Venues may have their own form: use theirs at work.

| Date and time | Where (bar, seat, table) | What happened (facts you saw and heard) | What you did | Who was told (manager, security, 100 / 101) | Outcome | Your name |
|---|---|---|---|---|---|---|
| | | | | | | |
| | | | | | | |
| | | | | | | |
| | | | | | | |

Tips:

- Describe signs ("slurred speech, held the bar to stand, spilled a drink") rather than labels ("drunk").
- Record the times you refused and offered water, food or a taxi.
- For an ID refusal, write the reason ("no ID shown", "photo did not match"), not the guest's personal details beyond what the venue policy requires.
- Keep the log where the manager can find it; do not photograph guests' documents unless venue policy and the law allow it.
