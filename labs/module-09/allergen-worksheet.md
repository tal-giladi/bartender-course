# Allergen worksheet (lesson 09.3)

Open `allergen-matrix.csv` in a spreadsheet (or print it).

1. In `allergens_from_spec`, write the allergens from the 14-item list that the spec itself contains (for example "egg" for a drink made with egg white).
2. In `check_label_items`, write each ingredient whose allergens depend on the brand and must be checked on the label or with the producer (for example a liqueur with no ingredient list, a soda, a cordial).
3. Remember the exemptions: spirits distilled from cereals, nuts or whey do not have to declare them; anything added after distillation is not exempt.
4. Compare with `allergen-matrix-solution.md`.
