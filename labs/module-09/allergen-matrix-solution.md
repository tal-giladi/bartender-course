# Allergen matrix — reference answers (lesson 09.3)

"From spec" means the allergen is in the drink as specified. "Check label" means it depends on the brand: read the label or the producer's information before answering a guest. Distilled spirits (gin, vodka, whisky, rum, tequila, cognac, pisco) are treated as not declaring cereals, nuts or whey because of the Annex II distillation exemptions.

| Drink | From spec | Check label |
|---|---|---|
| Dry Martini | sulphites (vermouth is wine-based) | olive brine |
| Manhattan | sulphites (vermouth) | bitters, cherry (syrup, colourings) |
| Old Fashioned | none | bitters, cherry |
| Negroni | sulphites (vermouth) | Campari (no ingredient list on many bottles) |
| Daiquiri | none | none |
| Margarita | none | triple sec |
| Whiskey Sour | egg (if egg white is used) | cherry |
| Cosmopolitan | none | cranberry juice drink, Cointreau |
| Mojito | none | none |
| Moscow Mule | none | ginger beer |
| Aperol Spritz | sulphites (Prosecco) | Aperol |
| Espresso Martini | none | coffee liqueur (some contain milk or other ingredients) |
| White Lady | none (egg white in common variations) | triple sec |
| Sidecar | none | triple sec |
| Pisco Sour | egg (if egg white; aquafaba is chickpea, not on the 14 list) | bitters |
| French 75 | sulphites (Champagne) | none |
| Tom Collins | none | cherry |
| Paloma | none | grapefruit soda |
| Bloody Mary | fish (Worcestershire: anchovy), celery (celery salt and celery stick) | Worcestershire (many brands also contain malt vinegar from barley: gluten), tomato juice, any ready-made mix (may contain mustard or other spices) |
| Mai Tai | tree nuts (orgeat: almond) | orange curaçao |

Things most learners miss: celery, fish and possible gluten in the Bloody Mary; sulphites in every vermouth and sparkling-wine drink; that beer (not in this list) contains gluten from barley or wheat; that a "nut-free" request also covers the shaker that just made a Mai Tai.
