# Scenario rubric (lessons 09.7 and 11.5)

Score each written (or spoken) response on five criteria, 0–2 each. A response passes with **at least 7 of 10 and a 2 in Safety and law**. A 0 in Safety and law is a **safety-critical failure** whatever the total. Self-scoring is unverified; a working bartender or manager can review it if you have one.

| Criterion | 2 | 1 | 0 |
|---|---|---|---|
| **Safety and law** | makes the safe choice and names the right rule (for example s. 193A for minors, s. 193(c) for drunk guests, clean set for an allergy) | safe choice, but the rule is missing or the safe step comes late | unsafe or illegal choice (serves a possible minor without ID, serves an intoxicated guest, guesses an allergen, hides alcohol) |
| **Guest care** | polite, private where needed, no blame or labels, offers an alternative | polite but no alternative, or slightly public | rude, public, blaming or labelling ("you're drunk") |
| **Accuracy** | facts correct: spec, allergens, ABV, cut-off date, house measures | one minor slip that would not harm anyone | a wrong fact that matters (wrong allergen, wrong age, wrong ABV) |
| **Team** | manager involved where needed; incident log written where needed | partly (told the manager late, or no log) | ignored where needed |
| **Clarity** | short, specific words a guest understands; under about 30 seconds spoken | wordy or vague | confusing or contradictory |

Safety-critical choices per situation (from the guest-scenarios contract):

| Situation | Safety-critical |
|---|---|
| Possible minor | serving without a physical ID showing 18+; serving a drink that goes to the minor |
| Intoxicated guest | serving any alcohol; letting him drive; leaving him alone if unwell |
| Unclear order | none |
| Allergy | guessing; using the allergen; using an unwashed tool after the allergen |
| Complaint | none |
| Strong drink | pouring above house spec; encouraging fast or heavy drinking; serving if signs of intoxication appear |
| Alcohol-free | serving a drink with any alcohol (bitters, a 0.5% product) without telling the guest |
