# Module 5 labs — Classic Cocktails I

Cards and sheets for learning the twelve Module 5 classics and for the module's practical piece (lesson 05.8). Everything is practised alcohol-free: water, teas, juices, syrups, soda, aquafaba and coffee stand in for spirits and liqueurs.

| File | Lesson | What it is |
|---|---|---|
| `spec-flashcards.md` | 05.1–05.8 | Printable flashcards for all twelve IBA specs, with the four templates |
| `recall-grid.md` | 05.8 | Blank 12-drink recall grid with the scoring rules (48 points, pass 39) |
| `recall-grid-solution.md` | 05.8 | Answer key and marking notes — check only after the grid is done |
| `twelve-drink-session.md` | 05.8 | Shopping list, drink order in blocks, target times, review plan |
| `twelve-drink-log.csv` | 05.8 | Session log to fill in (open in Excel, Google Sheets or LibreOffice) |

Templates used alongside: `templates/recipe-card.md` and `templates/practice-log.md`.

Data: specs are IBA (iba-world.com), checked 2026-10-17; variations and their sources are on each lesson's recipe cards. Target times in the session sheet are professional judgment for a home station, not exam limits. Units: 1 oz = 30 ml (bar convention), bar spoon 5 ml, dash about 0.8 ml.
