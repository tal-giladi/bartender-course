## Marking notes

- "Coupe" or "martini glass" both count for "chilled cocktail glass".
- Old Fashioned with 10–15 ml syrup instead of the cube: the method point is lost on this grid (the IBA spec is the cube), but note it is a correct house variation.
- Aperol Spritz soda: "splash" or 30 ml both count (IBA and Aperol's own recipe).
- Mojito glass: highball or Collins both count (IBA names no glass).
- Whiskey Sour: "coupe" alone loses the point; the IBA names a cobbler glass or the rocks serve.
