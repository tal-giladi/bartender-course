# Twelve-drink practice session

Lesson 05.8, Part 2. All twelve drinks as home-practice or alcohol-free versions, in an order that uses each tool in one block. Times are targets for a home station, not exam limits (professional judgment).

## Shopping list (one session)

| Item | Amount | Used in |
|---|---|---|
| Limes | 6 | Daiquiri, Margarita, Cosmopolitan, Mojito, Mule, garnishes |
| Lemons | 2 | Whiskey Sour, Martini and Cosmopolitan twists |
| Oranges | 2 | Old Fashioned, Negroni, Whiskey Sour, Spritz garnishes; orange juice |
| Fresh mint | 1 bunch | Mojito |
| White sugar and sugar cubes | a few spoons, 1 cube | Old Fashioned, Daiquiri, Mojito |
| 1:1 syrup (lesson 03.4) | 100 ml | Whiskey Sour, Espresso Martini, spares |
| Black tea, green tea (cold, brewed earlier) | 300 ml, 50 ml | stirred drinks, Whiskey Sour |
| Hibiscus tea or red grape juice | 50 ml | Negroni "Campari" |
| Cranberry drink | 50 ml | Cosmopolitan |
| Orange juice | 150 ml | Margarita, Cosmopolitan, Spritz |
| Ginger beer | 1 can or small bottle | Mule |
| Soda water and sparkling water | 1 litre | Mojito, Spritz |
| Chickpeas, 1 can (for aquafaba) | 20 ml liquid | Whiskey Sour |
| Coffee for espresso or moka pot | 1 shot | Espresso Martini |
| Salt, coffee beans, cocktail cherries or red grapes | a few | garnishes |
| Ice | 3–4 kg | everything |

## Order and targets

| Block | # | Drink (home version) | Target time | Tools |
|---|---|---|---|---|
| Prep | — | juice, syrup check, mint in water, garnishes, chill stemmed glasses, brew teas | ≤ 15 min | knife, board, press, peeler |
| Built and stirred | 1 | Negroni | ≤ 45 s | jigger, spoon |
| | 2 | Old Fashioned (cube) | ≤ 90 s | muddler, spoon |
| | 3 | Manhattan | ≤ 75 s | mixing glass, strainer |
| | 4 | Dry Martini | ≤ 75 s | mixing glass, strainer |
| Shaken | 5 | Daiquiri | ≤ 75 s | shaker, both strainers |
| | 6 | Margarita (half salt rim) | ≤ 90 s | shaker, salt plate |
| | 7 | Cosmopolitan | ≤ 60 s | shaker |
| | 8 | Whiskey Sour (aquafaba, reverse dry shake) | ≤ 90 s | shaker, both strainers |
| Coffee | 9 | Espresso Martini | ≤ 75 s after the coffee is made | shaker, both strainers |
| Long | 10 | Mojito | ≤ 90 s | muddler, spoon |
| | 11 | Moscow Mule | ≤ 30 s | spoon |
| | 12 | Aperol Spritz | ≤ 35 s | spoon |
| Reset | — | wash, dry, put away, wipe down | ≤ 15 min | |

Rinse the shaker once between drinks 4 and 5 (water only) and wash it after the Whiskey Sour. Measure the volume of three finished drinks of your choice.
