## Sparkling (hand-position drill)

| # | Step | Done (✓) |
|---|---|---|
| 1 | Bottle never pointed at a person or window | |
| 2 | Thumb on the cork (cap) from the moment the cage is touched | |
| 3 | Six turns to loosen the cage, cage left on for grip | |
| 4 | Bottle at 30–45° | |
| 5 | Turned the bottle, not the cork | |
| 6 | Slow release: sigh, not pop | |
| 7 | Two-stage pour to about two thirds of the glass | |

Safety rule: a 0 on sparkling step 1 or 2 means repeat the drill before ever opening a real sparkling bottle.
