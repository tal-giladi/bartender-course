# Technique rubric

Score each movement from your video. 2 = meets the standard on every rep, 1 = mostly, 0 = not yet. This is self-scored; ask a working bartender to review it if you can.

| Movement | Standard | Score (0–2) | Note |
|---|---|---|---|
| Measuring (jigger) | Within ±5% of target by weight; no drips; jigger held level | | |
| Free pour (optional) | Within ±10% of target on a count | | |
| Build | Glass → ice → ingredients in order; carbonated last; gentle lift | | |
| Stir | Spoon back against the glass, smooth and quiet, no splashing; 20–30 s | | |
| Shake | Tins sealed, hard and even, 10–15 s, safe grip; tins separate cleanly | | |
| Strain | Correct strainer; double strain where needed; no ice chips | | |
| Muddle | Pressing, not shredding; correct ingredient | | |
| Garnish | Clean cut, oils expressed toward the drink, placed consistently | | |
| Station reset | Tools back, surface wiped, bottles capped, within target time | | |
| Safety | Ice scoop, never a glass; knife cuts away from the hand; glass checked | | |

**Total:** ____ / 20 = ____ %. Practical technique minimum in the final assessment: 75%.

Unsafe knife handling or scooping ice with a glass is a safety-critical failure, whatever the score.
