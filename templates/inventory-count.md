# Inventory count

Count opening stock, add deliveries, count closing stock. For partial bottles, estimate in tenths or weigh them: (bottle weight − empty bottle weight) ÷ density.

| Item | Unit (bottle size, ml) | Par level | Opening count | Received | Closing count | Used (opening + received − closing) | Sold per POS (ml) | Variance (ml) | Variance % |
|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | |
| | | | | | | | | | |

Variance = used − sold. Variance % = variance ÷ sold × 100. Investigate anything beyond your bar's tolerance (often a few percent; it is set by the bar, not by law).
